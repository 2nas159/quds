# SOP — Weekly Performance Reporting

## 1. Weekly Check (every 2-3 days minimum, full review weekly)

Pull the following for each active Ad and Ad Set from Meta Ads Manager:

- Amount spent
- Reach & Impressions
- Frequency
- Results (messaging conversations)
- Cost per result
- CTR

## 2. Health Check Against Baselines

Reference `growth-marketing-context.md` for target ranges. Flag anything outside these ranges:

| Metric | Healthy | Flag |
|---|---|---|
| Cost per messaging conversation | 25-35 TRY | >45-50 TRY |
| Frequency | <2.5-3 | >3.5-4 |
| CTR trend | Stable or improving | Declining >15-20% over 7 days |

## 3. Weekly Report Format

```
## Weekly Ads Report — [Date Range]

### Spend & Results
- Total spend: [X] TRY
- Total messaging conversations: [X]
- Avg. cost per conversation: [X] TRY
- Estimated orders: [X] (cross-reference with WhatsApp order log)

### Active Ads Performance
| Ad Name | Spend | Conversations | Cost/Result | Frequency | Status |
|---|---|---|---|---|---|

### Flags / Actions Needed
- [List any ad exceeding cost or frequency thresholds]

### Recommended Actions This Week
- [e.g., add new creative to Ad Set X, expand geography, test new hook]
```

## 4. Monthly Reconciliation

- Compare Meta Ads spend/results against actual WhatsApp order volume and revenue (since not all orders are pixel-tracked — some come from organic follow-up messages).
- If flyer distribution (Kayaşehir) is active, cross-reference coupon code redemptions against that period's Meta performance in the same zone, to evaluate combined channel effect.
- Review margin: (Total revenue × ~20-25% margin) − ad spend − delivery/fuel costs = approximate net contribution from marketing efforts.

## 5. Decision Triggers

- **Scale budget up** if cost-per-conversation is stable/improving and frequency has room (<2.5) → increase by 10-20%.
- **Add creative, don't pause** if frequency is climbing but cost-per-conversation is still acceptable.
- **Refresh creative urgently** if cost-per-conversation has risen >30% from baseline over the reporting period.
- **Expand geography** if frequency is consistently high (>3) across all active ads in a zone despite creative refreshes.
- **Never** repeatedly turn campaigns off/on to "reset" — always prefer adding new ads within the existing Ad Set.
