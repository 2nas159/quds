# Template — Campaign / Ad Launch Checklist

Use before turning any new campaign, ad set, or ad ON.

---

**Campaign/Ad name:** [NAME]
**Date:** [DATE]

## Pre-Launch

- [ ] Objective set to OUTCOME_SALES (not Engagement, unless a deliberate test)
- [ ] Destination set to WhatsApp only
- [ ] Targeting: correct delivery zone(s), Arabic language, no interest layers added
- [ ] Budget set (300 TRY/day default for new ad sets, or scaled 10-20% from prior)
- [ ] Creative published as organic Page post first (if carousel or Messaging-objective ad)
- [ ] Ad created via "Use Existing Post" in Ads Manager UI
- [ ] CTA set to "Send WhatsApp Message"
- [ ] Creative reviewed against Quality Checklist (see sop-content-production.md):
  - [ ] Logo visible, unobstructed
  - [ ] Price accurate and current
  - [ ] Watermark not overlapping product
  - [ ] CTA + WhatsApp number present
  - [ ] Trust signals included
  - [ ] No market-sourcing mention anywhere
  - [ ] Arabic renders correctly RTL

## Launch

- [ ] New ad set to PAUSED existing ad set? → Confirm: adding to existing Ad Set, NOT pausing it
- [ ] Ad turned ON
- [ ] Old underperforming ad (if replacing) set to OFF individually — Ad Set itself stays ON

## Post-Launch (Day 1-3)

- [ ] Confirm ad is delivering (not stuck in review/rejected)
- [ ] Note baseline cost-per-conversation for comparison in coming days
